色彩系統

三層色彩哲學：Tier 1 美觀色跟著主題走，Tier 2 識別色／Tier 3 語意色固定不變。完整規則見 NDL.md §2。

字體

UI／資料一律 JetBrains Mono；標題／裝飾性文字用 Noto Serif SC，不進入內文。

JetBrains Mono — 0123456789 資料與介面文字
--fs-xl (20px) 示範；實際字級 token 見下表
Noto Serif SC — 標題與裝飾性文字
只用於標題層級，不進入內文

Spacing

4px 基準格線。新元件的 padding/gap/margin 一律從這組 token 選，不新增中間值。

Elevation

z-index 分五層，層級越高陰影越大越柔（跟整體手繪調性一致，不用生硬小陰影）。

動畫

只對 transform/opacity 做動畫。滑鼠移到方塊上觸發，感受三種時長的差異。

元件狀態

以熱鍵按鈕為例，展示 Normal / Hover / Active / Disabled 四種狀態（Hover 請實際移入滑鼠感受）。

NUG · Atom 可靠度 → 視覺確定感

可靠度不編碼成顏色（顏色留給 Confidence），編碼成線條的實/虛/粗/細。

定義／限制（最高）
因果（中等）
相關（中低）
經驗法則（較低）
類比（最低）

NUG · Observation 立場

支持 中立 反對

中立用中性灰，不用「弱信心」的藍——立場中立跟信心偏弱是兩個不同維度，不可混用（NUG §3）。

NUG · Confidence 分級

Strong
path_confidence ≥ 0.70
Medium
0.40 ≤ x < 0.70
Weak
0.15 ≤ x < 0.40
Hidden
x < 0.15（不顯示）

分級是離散判斷，不是連續漸層——不要用漸層色暗示信心是平滑變化的量（NUG §4）。
