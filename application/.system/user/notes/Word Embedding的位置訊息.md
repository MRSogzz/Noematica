## 詞嵌入原理：從數值表徵到語意理解

在現代大語言模型（LLM）中，**詞嵌入（Word Embedding）** 是將離散的語言符號轉化為連續數值向量的核心技術。然而，單純將文字轉換為數值向量是不夠的——語言的本質在於「語意」與「順序」的交織。一個完整的嵌入向量必須同時包含兩個關鍵組成部分：

- **詞元向量（Token Embedding）**：代表詞彙本身的語意內涵，透過神經網路學習而得。
- **位置向量（Positional Embedding）**：補充詞彙在句子中的順序資訊，這對於區分「我愛你」與「你愛我」的語義至關重要。

這兩個向量會相加（或拼接），形成最終的輸入表徵，餵入 Transformer 架構進行後續處理。

### 位置編碼：賦予模型順序感

由於自注意力機制本身不具備順序概念，我們必須在輸入中注入位置資訊。目前取得位置資訊主要有兩種途徑：

#### 1. 透過模型訓練學習（Learned Positional Encoding）

將位置索引（如第 1 個位置、第 2 個位置）視為可訓練的參數，讓模型在訓練過程中自動調整每個位置的向量。這種方法簡單直觀，但缺點是**無法處理超過訓練時所見過的最大長度**的序列。

#### 2. 透過數學公式計算（Fixed Positional Encoding）

利用預先定義的數學函數來生成位置向量，最著名的例子是原始 Transformer 論文中所使用的**正弦與餘弦波編碼（Sinusoidal Encoding）**。這種方法具有以下優點：

- **無需訓練**：位置向量是根據公式直接計算，不佔用模型參數。
- **可外推性**：能處理比訓練時更長的序列。
- **週期性模式**：不同頻率的波函數能捕捉不同尺度的位置關係。

### 絕對位置與相對位置的差異

在實際應用中，位置資訊的設計可以分為兩個層次：

- **絕對位置（Absolute Position）**：為每個位置賦予一個獨特的編碼，代表其在序列中的絕對順序（例如第 5 個詞）。這種方式簡單直接，但無法直接表達詞與詞之間的相對距離。

- **相對位置（Relative Position）**：編碼詞與詞之間的相對距離（例如「相隔 2 個位置」）。許多研究指出，**相對位置編碼**更能有效捕捉語法與語意結構，因為人類語言的本質更依賴於詞與詞之間的相對關係，而非絕對順序。近年來流行的 **RoPE（旋轉位置編碼）** 即是結合了絕對位置與相對位置優點的創新設計。

### 技術實現細節：矩陣運算與可導性

在具體實現中，嵌入向量的提取並非透過簡單的「檢索」對照表，而是透過**可導的矩陣相乘（Differentiable Matrix Multiplication）** 來完成：

1.  **詞元向量提取**：將輸入的 Token ID 視為 One-Hot 編碼（一個僅在對應位置為 1、其餘為 0 的向量），再乘以一個可訓練的**詞嵌入矩陣（Embedding Matrix）**。這個矩陣的每一列就是對應 Token 的詞元向量。這個過程本質上就是「查表」，但以矩陣運算的形式實現。

2.  **位置向量提取**：類似地，位置索引也透過與**位置嵌入矩陣**相乘來提取對應的位置向量。

3.  **可導性的關鍵意義**：由於整個操作是**可導的（Differentiable）**，模型的損失函數可以透過反向傳播（Backpropagation）將誤差訊號一路傳遞迴嵌入矩陣，持續**優化這些向量的數值**。這確保了嵌入層能隨著訓練過程不斷調整，使詞與詞之間的向量距離能更精確地反映它們的語意相似性，最終提升模型對複雜語言的理解能力。

### 總結

詞嵌入的完整原理涵蓋了語意表徵（詞元向量）、順序表徵（位置向量）、以及透過可導矩陣運算實現的端到端優化。從絕對位置到相對位置的技術演進，反映了研究者對語言結構本質的深入理解。掌握這些基礎設計，是理解現代大語言模型如何從原始文字中提取豐富語意的關鍵一步。
