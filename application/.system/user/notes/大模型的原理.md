## 大語言模型的運作機制：從預測到生成

大語言模型（Large Language Model, LLM）的核心運作機制，本質上是一種**自回歸模型（Autoregressive Model）**。它透過不斷**預測下一個字元（Next Token Prediction）**，一步步地生成連貫且有意義的內容。這種機制如同文字接龍：模型根據已經生成的文字，推測最可能出現的下一個詞，再將新詞接續到輸入中，反覆進行直到輸出完整回應。

### 前置處理：從原始文字到模型輸入

在模型開始學習或生成之前，原始文字必須經過一系列轉換，才能變成模型能夠理解的數值形式：

1.  **資料分詞（Tokenization）**：將原始文字切分為最小的處理單元——**Token**。Token 可以是單字、子詞（Subword）或甚至單個字元，取決於所使用的分詞器（如 BPE、SentencePiece）。例如，“Apple” 可能被切為 “Ap” 和 “ple”。

2.  **嵌入層（Embedding Layer）**：將每個 Token 對應到一個高維度的**數值向量**。這些向量在訓練過程中不斷調整，最終能捕捉 Token 之間的語意相似性。

3.  **位置編碼（Positional Encoding）**：由於自注意力機制本身不具備順序概念，我們需要額外為每個 Token 注入其在序列中的位置資訊。位置編碼通常使用正弦與餘弦函數生成，讓模型能區分「我愛你」與「你愛我」的差異。

![前置處理流程示意圖](https://placehold.co/700x200/2E7D32/FFFFFF?text=Tokenization+%E2%86%92+Embedding+%E2%86%92+Positional+Encoding "從文字到模型輸入的三階段處理")

### 核心引擎：Transformer 與多頭注意力

經過預處理的向量序列，會進入 **Transformer 架構**進行深層處理。其中，**多頭注意力機制（Multi-Head Attention）** 是 Transformer 的靈魂所在。

它讓模型在處理某個 Token 時，能夠「關注」到句子中所有其他 Token，並根據語境賦予它們不同的權重。例如，在「銀行」一詞出現時，若上下文有「存款」、「利息」，模型會加強對這些金融相關詞的關注；若上下文為「河岸」、「釣魚」，則會加強對地理相關詞的關注。這種動態的語境捕捉能力，是 LLM 能理解複雜語意的關鍵。

### 訓練階段的技術挑戰與對策

訓練數十億甚至數千億參數的大模型，面臨著許多優化挑戰。以下是三項核心技術，它們協同作用以確保訓練的穩定性與模型的最終效能：

- **歸一化（Normalization）**：用以**穩定梯度**。在每一層的輸出進行標準化，使數據分布維持在穩定範圍，防止數值爆炸或梯度劇烈震盪。
- **殘差連接（Residual Connection）**：用以**防止梯度消失**。透過建立跨層的捷徑，讓梯度能有效回流到淺層網路，使訓練極深層模型成為可能。
- **Dropout**：用以**解決過擬合（Overfitting）**。在訓練中隨機停用部分神經元，強迫模型學習更強健的特徵，提升對新數據的泛化能力。

### 推理階段：機率抽樣策略

當模型訓練完成，進入推理（生成）階段時，我們需要決定如何從模型預測的機率分佈中選取下一個 Token。不同的抽樣策略會顯著影響輸出的風格：

- **Temperature（溫度係數）**：控制機率分佈的「銳利度」。溫度越低，模型越傾向選擇機率最高的 Token（輸出更確定、更保守）；溫度越高，機率分佈越平坦（輸出更多樣、更具創造性）。

- **Top-K 抽樣**：只從機率最高的 K 個 Token 中進行抽取，排除其他低機率的選項，以過濾掉明顯不合適的候選詞。

- **Top-P（核採樣，Nucleus Sampling）**：動態選擇機率總和達到 P 的最小候選集合，在維持多樣性的同時，能動態調整候選詞的數量。

透過調整這些參數，開發者可以在**準確性**（選擇最可能的詞）與**多樣性**（探索更有趣的詞）之間取得平衡，使模型能根據不同任務需求彈性調整生成風格。

### 總結

大語言模型的運作涵蓋了從文字數位化、自注意力語境建模、到訓練穩定性技術與推理參數調優的完整流程。這個複雜的系統透過自回歸機制不斷預測下一個 Token，結合 Transformer 架構強大的特徵提取能力，最終實現了令人驚豔的語言理解與生成表現。
